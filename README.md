# النظام المحاسبي المتطور
## Advanced Accounting System

نظام محاسبي شامل ومتطور لإدارة العمليات المالية والمحاسبية للمؤسسات بكفاءة عالية ودقة متناهية.

---

## 🚀 المميزات الرئيسية

### 📊 إدارة محاسبية شاملة
- **دليل الحسابات**: نظام مرن لإدارة الحسابات المحاسبية
- **القيود المحاسبية**: تسجيل وترحيل القيود مع التحقق من التوازن
- **الفواتير**: إصدار وإدارة فواتير المبيعات والمشتريات
- **المخزون**: تتبع المخزون وتقييمه
- **الرواتب**: إدارة كشوف الرواتب والاستحقاقات

### 📈 تقارير مالية متقدمة
- **ميزان المراجعة**: تقرير شامل للأرصدة
- **قائمة الدخل**: تحليل الإيرادات والمصروفات
- **الميزانية العمومية**: عرض الأصول والخصوم
- **قائمة التدفق النقدي**: تتبع التدفقات النقدية
- **تقارير مخصصة**: إمكانية إنشاء تقارير حسب الحاجة

### 🔐 أمان متقدم
- **تشفير البيانات**: حماية شاملة للمعلومات الحساسة
- **التحكم في الوصول**: نظام صلاحيات متدرج
- **سجل المراجعة**: تتبع جميع العمليات
- **المصادقة الثنائية**: حماية إضافية للحسابات

### 🌐 واجهة مستخدم حديثة
- **تصميم متجاوب**: يعمل على جميع الأجهزة
- **واجهة عربية**: دعم كامل للغة العربية
- **سهولة الاستخدام**: واجهة بديهية وسهلة
- **تخصيص**: إمكانية تخصيص الواجهة

---

## 🛠️ التقنيات المستخدمة

### Backend
- **Python 3.11+**: لغة البرمجة الأساسية
- **FastAPI**: إطار عمل سريع وحديث
- **SQLAlchemy**: ORM متقدم لقاعدة البيانات
- **PostgreSQL**: قاعدة بيانات قوية وموثوقة
- **Redis**: تخزين مؤقت وسريع

### Frontend
- **React 18+**: مكتبة واجهة المستخدم
- **TypeScript**: لغة برمجة قوية
- **Material-UI**: مكتبة مكونات UI
- **Chart.js**: رسوم بيانية تفاعلية

### DevOps
- **Docker**: حاويات التطبيق
- **Docker Compose**: إدارة الخدمات
- **Nginx**: خادم ويب وموزع تحميل
- **Prometheus**: مراقبة الأداء
- **Grafana**: لوحات المراقبة

## 📦 التثبيت والإعداد

### المتطلبات
- Python 3.11+
- Node.js 18+
- PostgreSQL 15+
- Redis 7+
- Docker (اختياري)

### التثبيت السريع
```bash
# استنساخ المشروع
git clone https://github.com/your-org/accounting-system.git
cd accounting-system

# تشغيل سكريبت الإعداد
chmod +x setup_dev_environment.sh
./setup_dev_environment.sh

# تفعيل البيئة الافتراضية
source venv/bin/activate

# تشغيل قاعدة البيانات
make docker-up

# إعداد قاعدة البيانات
make setup-db

# تشغيل التطبيق
make dev
```

### التثبيت باستخدام Docker
```bash
# تشغيل جميع الخدمات
docker-compose up -d

# عرض السجلات
docker-compose logs -f

# إيقاف الخدمات
docker-compose down
```

## 🚀 البدء السريع

### 1. تسجيل الدخول
- افتح المتصفح وانتقل إلى `http://localhost:8000`
- استخدم البيانات الافتراضية:
  - **اسم المستخدم**: admin
  - **كلمة المرور**: admin123

### 2. إعداد الحسابات
- انتقل إلى "إدارة الحسابات"
- أضف الحسابات المطلوبة
- نظم الحسابات في هيكل منطقي

### 3. تسجيل القيود
- انتقل إلى "القيود المحاسبية"
- أنشئ قيد جديد
- تأكد من توازن القيد

### 4. إصدار الفواتير
- انتقل إلى "الفواتير"
- أنشئ فاتورة جديدة
- أضف العناصر والتفاصيل

### 5. عرض التقارير
- انتقل إلى "التقارير"
- اختر نوع التقرير المطلوب
- حدد الفترة الزمنية
